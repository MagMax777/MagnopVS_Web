# MagnopVS · Codex de los Grandes: Mentor System (v6.6)

## 1. Concept: Caminos de Maestría
Instead of static profiles, every historical figure is now a **Mentor Legendario**. Unlocking a mentor opens a "Mastery Path" where the player synchronizes with their life's work.

## 2. Shared Data Structure (Mentor Sheet)
- **ID:** Historical unique identifier.
- **Clase/Rol:** RPG role (e.g., Polímata, Libertadora, Sanadora).
- **Rareza:** Común | Raro | Épico | Legendario | Mítico.
- **Atributos (0-100%):** Fuerza, Destreza, Carisma, Inteligencia, Brillantez.
- **Virtudes:** Core values (e.g., Curiosidad, Coraje).
- **Habilidades Emblemáticas:** 3-4 specific skills.
- **Desafíos:** Historical obstacles faced.
- **Lección para el Jugador:** The practical takeaway for MLH.
- **Resources:** Recommended books/films.
- **Misión MLH:** A real-world challenge to unlock progress.
